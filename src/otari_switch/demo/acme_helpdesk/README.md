# Acme Helpdesk

A small support app with five AI features: summarise a ticket, classify its priority, extract fields as JSON,
draft a reply, and pick the next action with a tool call. Every call goes straight to a frontier model today.

It exists to demo [Otari Switch](https://github.com/): run `otari-switch demo` to watch it move these calls to
open-weight models through Otari.
